# Calcolatore Stipendio Netto

Web application sviluppata in Python con Flask che consente di stimare lo stipendio netto mensile a partire dalla retribuzione annua lorda (RAL) e da ulteriori informazioni fornite dall'utente.

## Funzionalità

- Inserimento della RAL
- Inserimento di informazioni aggiuntive rilevanti ai fini del calcolo
- Stima del netto mensile
- Interfaccia web dalla quale inserire le info

## Tecnologie utilizzate

- Python
- Flask
- HTML


## Passi da seguire: Installazione

Clonare il repository:

```bash
git clone https://github.com/pytia404/calcolatore-stipendio-netto.git
```

Entrare nella cartella del progetto:

```bash
cd calcolatore-stipendio-netto
```

Installare le dipendenze:

```bash
pip install -r requirements.txt
```

## Avvio dell'applicazione

Eseguire:

```bash
python app.py
```

Aprire il browser all'indirizzo:

```text
http://127.0.0.1:5000
```
